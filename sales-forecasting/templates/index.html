    About Project

    SALES FORECASTING USING TIME-SERIES ANALYSIS

    Industry-Oriented AI/ML Full-Stack Application

    Project Objective

    Develop a full-stack web application that analyzes historical sales data, identifies trends, trains multiple forecasting models, compares their performance, and predicts future sales.

    Technologies Used
    • Frontend: HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, Chart.js
    • Backend: Python, Flask, REST API
    • ML Models: ARIMA (Statsmodels), Random Forest, Linear Regression (Scikit-learn), Naive Forecast
    • Data: Pandas, NumPy, SQLite
    Features
    • Interactive Dashboard with KPIs
    • Multiple Time-Series Forecasting Models
    • Model Performance Comparison
    • CSV Data Upload and Validation
    • Forecast History with SQLite Storage
    • CSV Export of Forecasts
    • Business Insights Generation
